# 東方リトルメイド：将棋（Touhou Little Maid Shogi）

[简体中文](README.md) | [English](README_en.md) | [日本語](README_ja.md)

**[Touhou Little Maid](https://github.com/TartaricAcid/TouhouLittleMaid)** に、実際に設置して遊べる将棋盤を追加するアドオンMODです。メイドとの本将棋に加え、道具として収集した詰将棋にも挑戦できます。

## 追加される遊び

### 本将棋

将棋盤は東方リトルメイドの祭壇で、次の材料から作成します。

- 任意の原木 1個
- 任意の板材 2個
- 黒色の染料 1個
- 赤色の染料 1個
- ダイヤモンド 1個
- 祭壇パワー 0.1

設置には横一列に3ブロック分の空間が必要です。盤の向かい側にメイドを座らせると、プレイヤーが先手で対局を始められます。自分のメイドとだけ対局できるかどうかは、東方リトルメイド本体のボードゲーム設定に従います。

対局中は素手で操作します。

1. 自分の盤上駒、または駒台の持駒の山を右クリックして選択します。
2. 移動先を右クリックして、移動または駒打ちを行います。
3. 成りを選べる場合は選択画面が開き、強制成りの場合は自動的に成ります。
4. プレイヤーが指した後、メイドが考えて自動的に応手します。
5. 素手で盤台の左右にあるリセット領域を右クリックすると、いつでも初期局面に戻せます。

プレイヤーは常に先手です。メイドがいなくても盤の設置や表示はできますが、対局を進めるにはメイドを着席させる必要があります。

### 詰将棋の局面道具

詰将棋の局面道具には、初期局面、手数、作者が保存されています。ツールチップで `Shift` を押すと、盤面と双方の持駒を確認できます。道具を持って将棋盤を右クリックすると、進行中や終了済みの対局も含め、盤面が直ちにその問題へ置き換わります。道具は消費されず、何度でも使用できます。

問題ではプレイヤーが常に先手の攻方です。メイドが着席している場合、メイドは玉方として、詰みから逃れるか、詰むまでの手数をできるだけ長くする応手を選びます。

#### 詰将棋とは

詰将棋は、指定された手数以内に連続王手で強制的に詰ませることを目的とする将棋の問題です。チェスやシャンチーのエンドゲーム問題、一般的な将棋の終盤問題とは次の点が異なります。

- 攻方は毎手必ず王手をかけ、最後の手で詰ませなければなりません。
- 駒得や有利な局面ではなく、玉方のすべての合法手に対して詰みが成立する必要があります。
- 実戦の終盤とは限らない創作問題であり、攻方の玉が盤上に存在しない場合もあります。
- 持駒を盤上へ打てる将棋独自のルールが、解答の重要な要素になります。
- 「X手詰」の手数には攻方と玉方の両方の着手を数えます。3手詰なら通常は「王手、応手、詰み」の3手です。

指定手数を使い切っても詰まない場合や、プレイヤーの手番で合法な王手が一つもなくなった場合は「不正解」になります。通常問題、エンチャント表示の名作問題、特殊な長編問題も、読み込み方と操作方法は共通です。

## 局面道具の入手場所

自然生成される詰将棋の局面道具は、次のチェストから入手できます。

- 村の製図家の家にあるチェスト
- 要塞の図書室にあるチェスト

局面、手数、作者は入手した道具に保存されます。特殊な問題も同じ場所に出現するため、別の構造物を探す必要はありません。

## メイドの好感度

- 通常対局で自分のメイドに勝つと、東方リトルメイド本体のボードゲーム勝利と同じ基準で好感度が上がります。
- 通常の詰将棋を初めて正解した場合も、同じ基礎報酬を得られます。
- 名作詰将棋は基礎報酬の3倍、ミクロコスモスは5倍です。
- 正解済みの記録は、プレイヤーごと・初期局面ごとに保存されます。同じ局面を再び解いても、別のメイドを相手にした場合を含め、好感度は再度増えません。
- マルチプレイサーバーでも各プレイヤーの記録は別々です。すべての報酬には、東方リトルメイド本体のボードゲーム報酬クールダウンが適用されます。

## 動作要件

- Minecraft 1.21.1
- NeoForge 21.1.215以降の互換バージョン
- Touhou Little Maid 1.4.1以降
- Java 21

クライアントとサーバーの両方に導入してください。内蔵エンジンは純Java実装のため、対応するMinecraftを実行できるWindows、Linux、macOSなどで利用できます。マルチプレイ時の思考処理はプレイヤー側のクライアントで行われます。
