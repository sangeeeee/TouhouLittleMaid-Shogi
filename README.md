# 车万女仆：将棋（Touhou Little Maid Shogi）

[简体中文](README.md) | [English](README_en.md) | [日本語](README_ja.md)

这是一个为 **[车万女仆（Touhou Little Maid）](https://github.com/TartaricAcid/TouhouLittleMaid)** 制作的附属模组。它加入了可实际摆放的日本将棋棋盘，让玩家能够与自己的女仆进行完整对局，也可以使用收集到的残局道具挑战诘将棋。

## 模组内容

### 日本将棋

棋盘通过车万女仆的祭坛合成，需要：

- 1 个任意原木
- 2 个任意木板
- 1 个黑色染料
- 1 个红色染料
- 1 颗钻石
- 0.1 祭坛能量

放置棋盘时，横向需要连续三个方块的空间。让女仆在棋盘对面就座后，玩家即可执先手开始对局；是否只能与自己的女仆对弈，遵循车万女仆本体的棋类游戏设置。

对局时需要空手操作：

1. 右击自己的棋子或驹台上的持驹，将其选中。
2. 右击目标格完成移动或打入。
3. 可以升变时会显示选择界面；必须升变时则会直接升变。
4. 玩家落子后，女仆会思考并自动回应。
5. 空手右击棋墩左右的重置区域，可以随时恢复到初始局面。

玩家始终执先手方。棋盘可以正常放置并显示棋局，但没有女仆就座时无法继续对弈。

### 诘将棋残局道具

每个诘将棋残局道具都保存了一道题目的初始局面、规定手数和作者信息。按住 `Shift` 查看道具提示时，可以预览盘面和双方持驹。手持道具右击任意状态的将棋棋盘，会立即用该题目替换当前棋局；残局道具不会因此消耗，可以重复使用。

载入题目后玩家总是先手，并负责进攻。若棋盘对面有女仆，她会作为守方选择应手，并尽量逃脱或延长被将死所需的手数。

#### 诘将棋是什么？

诘将棋是以“在规定手数内强制将死”为目标的日本将棋排局。它与象棋残局、国际象棋残局或一般的将棋残局并不完全相同：

- 诘将棋的目标固定为连续王手并最终将死，不是判断优势、求和或赢得残局。
- 进攻方的每一步都必须造成王手；不王手的走法不会被允许落下。
- 守方可以选择任意合法应手，因此答案必须能够应对最佳防守。
- 题目是为解谜专门构造的，进攻方甚至可以不在棋盘上放置王将。
- 将棋允许把持驹重新打入棋盘，这通常也是解题的重要部分。
- “X 手诘”的手数同时计算攻方和守方的着手。例如三手诘通常是“王手、应手、将死”三步。

如果超过道具标注的手数仍未将死，或者轮到玩家时已经不存在任何能够继续王手的合法走法，答案会被判定为“不正确”。普通残局、带有附魔闪光的名作题目以及特殊长篇题目都使用相同的载入与操作方式。

## 在哪里寻找残局道具

自然生成的诘将棋残局道具可以在以下箱子中找到：

- 村庄制图师房屋的箱子
- 要塞图书馆的箱子

题目的规定手数、初始局面和作者会随获得的道具一同保存。特殊题目也可能在相同地点出现，无需另外寻找其他建筑。

## 女仆好感度

- 在普通将棋中战胜自己拥有的女仆，会按车万女仆本体的棋类胜利奖励增加好感度。
- 首次正确解答一道普通诘将棋，也会获得一次相同的基础好感度奖励。
- 名作诘将棋的奖励为基础奖励的 3 倍，《ミクロコスモス》的奖励为基础奖励的 5 倍。
- 每道诘将棋按玩家记录完成状态。同一名玩家重复解答同一个初始局面时，即使更换女仆，也不会再次获得好感度。
- 多人服务器会分别保存每名玩家已经完成的题目。所有好感度奖励仍遵循车万女仆本体的棋类奖励冷却规则。

## 运行需求

- Minecraft 1.21.1
- NeoForge 21.1.215 或更高的兼容版本
- Touhou Little Maid 1.4.1 或更高版本
- Java 21

模组需要同时安装在客户端和服务器。内置将棋引擎为纯 Java 实现，可在 Windows、Linux 和 macOS 等能够运行对应 Minecraft 版本的平台上使用；多人游戏中的思考计算由玩家客户端完成。
